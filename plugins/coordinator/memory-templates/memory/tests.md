# Self-tests

Each test: the question, the expected answer, the rule or note it should use, then your mark (right or wrong) and a comment.

## Sample questions (invented; replace as you learn)

1. "What's on today?" Expected: today's tasks with assignee, then today's meetings. Mark: ___ Comment: ___
2. "What did Bob accomplish last week?" Expected: only tasks assigned to Bob and logged completed last week; if none logged, says so. Mark: ___ Comment: ___
3. "Add a task: Bob to send the invoice, due Friday." Expected: saved with an absolute date, date read back. Mark: ___ Comment: ___
