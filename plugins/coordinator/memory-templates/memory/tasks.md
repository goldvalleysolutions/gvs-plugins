# Tasks

One line per task. Dates are absolute (YYYY-MM-DD). Coordinator edits this file when you chat; you can edit it too.

Format: `- [ ] T-001 | title | assignee: name | due: YYYY-MM-DD | logged: YYYY-MM-DD`
When done: `- [x] T-001 | title | assignee: name | due: YYYY-MM-DD | logged: YYYY-MM-DD | completed: YYYY-MM-DD | note`

## Open

- [ ] T-000 | (example) Call the supplier about the delivery | assignee: Bob | due: 2026-01-15 | logged: 2026-01-12

## Completed

- [x] T-0000 | (example) Send the quote | assignee: me | due: 2026-01-09 | logged: 2026-01-05 | completed: 2026-01-08 |
