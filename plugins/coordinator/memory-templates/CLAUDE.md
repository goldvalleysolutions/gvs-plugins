# Coordinator notes (hot cache)

Copy this folder into your working folder as `memory/coordinator/` during setup. Keep this file short.

- People I assign work to: see `people.md`
- Today snapshot: tasks due today (with assignee) and today's meetings. (Change by chatting.)
- Completed means: marked done in `tasks.md`. (Change by chatting.)
- Nothing is sent, posted or paid without an explicit yes in chat.
- Coordinator knows only what is logged here and what is on the connected calendar.
