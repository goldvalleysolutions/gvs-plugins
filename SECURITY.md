# Security

Please report security issues privately. Do not open a public GitHub issue or post the details in a pull request.

The main channel is GitHub's private vulnerability reporting on this repository:

https://github.com/goldvalleysolutions/gvs-plugins/security/advisories/new

If you cannot use that form, email info@goldvalleysolutions.com and put "security" in the subject line.

We will acknowledge your report and let you know what we find. These plugins keep notes as files in the user's own folder and do not send, post, or pay without an explicit yes in chat. Please include enough detail for us to reproduce the issue, and do not include real customer data in the report.
